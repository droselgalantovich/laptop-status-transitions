# Тестовое задание: статусы ноутбука на складе

**Время — до 1 часа.** Пользоваться AI можно.

## Задача

Напишите на TypeScript функцию, которая меняет статус ноутбука, и тесты к ней.

### Допустимые переходы

- **На складе** → Бронь, Продан, Списан
- **Бронь** → На складе, Продан
- **Продан** → На складе (возврат не позднее 14 дней после продажи)
- **Списан** — дальше никуда

## Требования

- Недопустимый переход возвращает понятную ошибку.
- Каждое изменение записывается в историю: какой статус был, какой стал, дата.

## Как работать

Сначала напишите в README план из 3–5 пунктов, потом код.

Коммиты делайте с префиксами:

- `ai:` — то, что сгенерировал AI, без изменений;
- `manual:` — ваш код и ваши правки AI-кода.

В конце README ответьте на два вопроса:

- что в задании было непонятно и как вы это решили;
- какие запросы вы давали AI.

Тесты должны проходить.
