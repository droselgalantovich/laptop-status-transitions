# Статусы ноутбука на складе

Тестовое задание: функция на TypeScript для изменения статуса ноутбука с проверкой допустимых переходов и записью истории. Условия — в [TZ.md](./TZ.md).

## План реализации

1. Определить типы статусов, ноутбука и записи истории; описать решения по неоднозначностям, включая границу срока возврата и формат ошибок.
2. Реализовать разрешённые переходы и возврат не позднее 14 дней после последней продажи, предусмотрев передачу времени для воспроизводимых тестов.
3. Добавить запись предыдущего статуса, нового статуса и даты при успешном переходе; при ошибке сохранять статус и историю без изменений.
4. Написать и запустить тесты для всех переходов, границы 14 дней, истории и повторной продажи; проверить типы TypeScript.
5. Дополнить README командами запуска, ответами о неясностях задания и использованных запросах к AI; проверить готовность репозитория к сдаче.

## Коммиты

- `ai:` — код и другие материалы, сгенерированные AI без ручных изменений.
- `manual:` — собственный код автора задания и его ручные правки AI-кода.
